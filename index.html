1はじめに

Milleaf は、VRChat のスクリーンショットから写真集を作る Windows アプリです。フォルダを選ぶと、似た写真をまとめて、テンプレートに合わせて写真を並べます。できたあとは、写真や文字、飾りを 1 ページずつ直せます。

写真を選ぶ
月ごとのフォルダから読み込み、連写や似た写真を 1 枚にまとめます
自動で本にする
テンプレートは 5 種類（シンプル、雑誌風、フィルム・インスタント、ぎゅうぎゅう、漫画）。別売の公式追加テンプレートを入れると増えます
直す
写真の入れ替え、レイアウトの変更、文字と飾りの追加、モザイク、トリミング、色の調整
書き出す
PDF、連番画像（PNG・JPEG）、電子書籍（EPUB）、印刷所の入稿データ、VRChat の中で読める本（unitypackage）

2入れ方と起動

インストールはありません。ZIP を展開して使います。

  1. BOOTH から ZIP（Milleaf-（版）-win-portable.zip）をダウンロードします。
  2. ZIP を右クリックし、「プロパティ」の下にある「許可する」にチェックがあれば入れて「OK」を押します（起動のときの警告が減ります）。
  3. ZIP を右クリックし、「すべて展開」で好きな場所へ展開します。C:\Program Files の中は書き込めないことがあるので避けてください。
  4. 展開したフォルダの Milleaf.exe をダブルクリックします。
  5. 「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。Milleaf には電子署名を付けていないため、はじめての起動で出ます。

ZIP の中から直接は起動できません。ウイルス対策ソフトが止めたときは、展開したフォルダを除外に加えてください。

データの置き場所

  • 作った本と設定、テンプレートは %APPDATA%\Milleaf に保存されます。「設定」の「データの場所」にある「フォルダを開く」で開けます。
  • このフォルダは、アプリのフォルダを消しても残ります。新しい版にしても、前の本がそのまま見えます。
  • USB メモリなどで持ち運ぶときは、Milleaf.exe と同じ場所に Milleaf-data という空のフォルダを作ってから起動します。データはそこに保存されます。
  • 元のスクリーンショットは読むだけで、変更も移動もしません。
  • やめるときは、Milleaf のフォルダと %APPDATA%\Milleaf を削除します。

3本を作る

作り方は 2 つあります。

  • おまかせでつくる: フォルダを選ぶだけで、全部のテンプレートで組んだ候補が並びます。いちばん早い方法です。
  • 新しい本: 使う写真を選び、テンプレートとページの設定を決めてから本にします。

スクリーンショットの場所

  • VRChat の写真は、ふつう ピクチャ\VRChat に月ごとのフォルダ（2026-09 など）で保存されています。Milleaf はこの場所を自動で探します。
  • 見つからないときや、ほかの場所にも写真があるときは「場所を追加」で選びます。選んだ場所は次から覚えています。
  • 一覧で、使う月にチェックを入れます。「直近」「直近 3 つ」「すべて」でまとめて選べます。

おまかせでつくる

  1. 本棚の「おまかせでつくる」を押します。
  2. 使う月にチェックを入れます。
  3. 「本の厚さ」（少なめ 30 枚・ふつう 60 枚・多め 110 枚・全部使う）と「文字」（入れない・日付だけ・日付とワールド名）を選び、「つくる」を押します。
  4. 同じ写真を全部のテンプレートで組んだ候補が並びます。気に入ったカードを押すと本になります。

新しい本

  1. 本棚の「新しい本」を押します。
  2. 写真のフォルダ: 使う月にチェックを入れて「写真を読み込む」を押します。VRChat 以外の画像は、右の「フォルダを追加」から読み込めます。
  3. 写真を選ぶ: はじめは全部が選ばれています。使わない写真の印を外します。
  4. 本の設定: テンプレートを選び、タイトルや写真の密度などを決めて「本をつくる」を押します。右上に、いまの設定で組んだときのページ数が出ます。

写真を選ぶ画面のキー:

P Enter使う X Delete使わない Space使う・使わないを切り替え ← → ↑ ↓前後の写真へ S大きく見る・一覧だけを切り替え
  • 「似た写真をまとめる」を押すと、連写や構図の近い写真を組にして、鮮明な 1 枚だけを選びます。組は「+N 枚」から開いて選び直せます。
  • 「ワールド」に切り替えると、写真に記録されたワールド名ごとに並びます。
  • 「紙の本」: 印刷所に出す予定なら、チェックを入れます。チェックを入れると、写真を少し明るくしておきます（紙は画面より暗く刷り上がるため）。
  • 「始め方」で「枠だけの本から始める」を選ぶと、写真を入れずに表紙と数ページだけで始まります。
  • 本の大きさ（A5 など）はテンプレートで決まります。

写真を選んでおく

本棚の「写真を選んでおく」で、本にする前に写真だけを選び、名前を付けて保存できます。保存したものは「選んでおいた写真」のタブにあり、「この写真で本をつくる」で使えます。写真そのものは複製せず、どの写真を選んだかだけを保存します。

4本を直す

本を開くとエディタになります。左に写真、中央にページ、右に選んだものの設定、下にページの一覧が並びます。

  • 保存: 自動で保存されます。Ctrl + Z で 1 つ前に戻せます。
  • 写真を替える: 左の写真をページの枠へドラッグします。枠どうしをドラッグすると入れ替わります。
  • 写真の位置と大きさ: 枠の中の写真をドラッグすると位置が、Alt + ホイールで拡大が変わります。枠の大きさは角をドラッグするか、Ctrl + ホイールで変えます。
  • レイアウト: ページを選び、右の「レイアウトを変える」から選びます。写真は残したまま、配置だけが変わります。
  • 文字と飾り、写真枠: 上の「追加」から足します。文字はダブルクリックで直接書けます。フキダシもここにあります。
  • 本全体の見た目: 上の「テンプレート」で本全体を組み直し、「配色」で紙と文字の色、差し色を変えます。「本の情報」では、タイトルや綴じ方向、文字の大きさ、奥付を変えられます。
  • ページ: 下の一覧で追加や複製、削除をします。ドラッグで並べ替えられます。
  • まとめて組み直す: 上の「おまかせ」で、写真を残したまま本全体を組み直したり、キャプションや表紙をまとめて変えたりできます。

操作の一覧は、右下の「?」か ? キーで出ます。その画面でできることとキーが並びます。

写真の編集

枠の写真をダブルクリックすると「写真を編集」が開きます。モザイク、トリミング、色の調整はここでします。

  • 写り込んだ人やネームタグを隠すときは、左の「四角」「楕円」「なげなわ」「ブラシ」で範囲を指定し、右で「モザイク」「ぼかし」「塗りつぶし」を選びます。
  • トリミングと回転、反転もここでできます。
  • 色は「印刷向け」「明るく」などの見本から選ぶか、明るさやコントラストを動かします。同じ日や同じワールドの写真にまとめてかけることもできます。
  • 元のファイルは変更しません。「適用」のあとも、いつでも編集し直せます。「画像として保存」で、編集した 1 枚を PNG か JPEG で保存できます。

6VRChat の中で読める本

アバターに持たせて、VRChat の中でページをめくれる本を書き出せます。PC 版の VRChat 用で、Quest には対応していません。

必要なもの

  • アバターをアップロードできる Unity のプロジェクト（Unity 2022.3 と VRChat SDK の Avatars。2022.3.22f1 で動作を確かめています）
  • Modular Avatar（1.18 で動作を確かめています）。VCC（VRChat Creator Companion）か ALCOM で、先にプロジェクトへ入れておきます

書き出しの設定

  • 本の高さ（手に持つなら 15〜25 cm）、テクスチャの大きさ（1024・2048・4096）、付ける場所（左手・右手・胸の前）を選びます。デスクトップ（VR なし）で使うなら「胸の前」が見やすい位置です。
  • 「アバターに増える容量」に、テクスチャメモリとダウンロードの大きさが出ます。
  • 本の写真は、ほかの人にも見えます。

アバターに入れる

  1. Unity でアバターのプロジェクトを開き、書き出した .unitypackage を取り込みます（ダブルクリックか、Assets → Import Package → Custom Package）。
  2. Assets/Milleaf/（題名）_（月日）/Milleaf.prefab を、ヒエラルキーのアバターの中へドラッグします。選んだ場所（手か胸の前）に自動で置き直されます。
  3. そのままアップロードします。
  • 向きを変えるときは、ヒエラルキーで Milleaf を選び、インスペクターの Rotation を変えます。
  • 手の位置がずれたときは、Unity のメニューの Tools → Milleaf →「本を手に合わせ直す」を使います。
  • 同じ本を書き出し直して取り込むと、前の中身が新しくなります。同じ本は 1 つのアバターに 1 冊までです。
  • 本のフォルダには README.txt が入っています。

7新しい版にする・元に戻す

新しい版にする

  1. 新しい ZIP を BOOTH からダウンロードし、いまのフォルダとは別の場所に展開します。
  2. 新しい Milleaf.exe を起動します。本と設定はそのまま使えます。起動したときに、それまでのデータのバックアップも作ります。
  3. 問題なく動いたら、古いフォルダを削除します。
  • 古いフォルダに Milleaf-data を作っていたときは、起動したときの案内で「写して使う」を選びます。
  • うまく動かないときは、古いフォルダの Milleaf.exe でこれまでどおり使えます。ただし、新しい版で保存した本は、古い版では見るだけになります。
  • 「設定」の「新しいバージョンが出たら知らせる」をオンにすると、新しい版が出たときに本棚の右上に知らせが出ます。1 日 1 回、公開している版の情報を読むだけで、こちらからは何も送りません。

バックアップから戻す

  • 新しい版をはじめて起動したとき、それまでの本とテンプレート、設定を自動で写しておきます（写真そのものは写しません）。
  • 「設定」の「バックアップから戻す」で、一覧から時点を選んで「戻す」を押します。戻す直前の状態も写しておくので、あとから戻し直せます。

8困ったとき

起動しない、すぐに閉じる

ZIP をすべて展開してから、展開したフォルダの Milleaf.exe を起動しているか確かめてください。C:\Program Files の中に置いた場合は、ほかの場所へ移します。ウイルス対策ソフトが止めている場合は、展開したフォルダを除外に加えます。

「Windows によって PC が保護されました」と出る

「詳細情報」を押してから「実行」を押します（2 章）。

VRChat の写真が見つからない

VRChat の設定で写真の保存先を変えている場合は、自動では見つかりません。「場所を追加」で写真のフォルダを選んでください。

「この本の写真が N 枚見つかりません」と出る

本を作ったあとに写真を移動したか削除したか、写真のある外付けドライブが外れています。写真を元の場所に戻すと、また表示されます。写真が見つからないあいだは書き出せません。

写真の読み込みに時間がかかる

はじめて読むフォルダは、写真を 1 枚ずつ開くので数分かかることがあります。2 回目からは速くなります。

「この PC に無いフォント」と出る

本で使っている書体が、この PC にありません。そのまま書き出すと別の書体で出ます。書体を選び直すか、「設定」の「追加したフォント」からフォントを追加してください。

書き出せない

「書き出せませんでした」のあとに理由が出ます。ディスクの空きが足りない、書き込めないフォルダを選んだ、ファイルをほかのアプリで開いている、フォルダの場所が長すぎる、のどれかです。別のフォルダを選んで試してください。

体験版で書き出せなくなった

体験版の書き出しは 1 日 3 回までです。日付が変わると 3 回に戻ります。製品版には回数の制限はありません。

VRChat で本が出たままで、メニューも無い

アバターのプロジェクトに Modular Avatar が入っていません。入れてからアップロードし直してください。

VRChat でメニューが見つからない

Expression メニューの「More」の中を見てください。見つからないときは、Unity でプレハブがアバターの中にあるか確かめます。

ほかの人がページをめくれない

VRChat の設定の「Avatar Interactions」で、その人を許可してください。

不具合を知らせたい

アプリの右下の吹き出しのボタン（F8）で、その画面のスクリーンショットと一緒にメモを残せます。「まとめてフォルダに書き出す」でできたフォルダを添えて、入手したお店からお問い合わせください。

1Getting started

Milleaf is a Windows app that makes photo books from your VRChat screenshots. Choose a folder, and it groups similar shots and lays out the pages from a template. After that, you can change the photos, text and decorations page by page.

2Install and start

There is no installer. You unzip Milleaf and run it.

  1. Download the ZIP (Milleaf-(version)-win-portable.zip) from BOOTH.
  2. Right-click the ZIP and open Properties. If there is an Unblock checkbox at the bottom, tick it and click OK. This cuts down the warnings when you start Milleaf.
  3. Right-click the ZIP, choose Extract All and pick a folder. Avoid C:\Program Files, where Milleaf may not be able to save.
  4. Double-click Milleaf.exe in the extracted folder.
  5. If "Windows protected your PC" appears, click More info, then Run anyway. Milleaf is not code-signed, so this shows up the first time you run it.

Milleaf cannot run from inside the ZIP. If your antivirus blocks it, add the extracted folder to its exclusions.

Where your data is saved

  • Books, settings and templates are saved in %APPDATA%\Milleaf. To open it, go to Settings, Data location, Open folder.
  • This folder stays when you delete the app folder, so your books are still there after you update.
  • To carry Milleaf on a USB drive, create an empty folder named Milleaf-data next to Milleaf.exe before you start it. Your data is then saved there.
  • Milleaf only reads your screenshots. It never changes or moves them.
  • To remove Milleaf, delete the Milleaf folder and %APPDATA%\Milleaf.

3Make a book

There are two ways.

  • Make one for me: choose folders, and Milleaf lays the photos out in every template so you can pick one. This is the quickest way.
  • New book: choose the photos yourself, then the template and page settings.

Screenshot folder

  • VRChat usually saves photos in Pictures\VRChat, in one folder per month (such as 2026-09). Milleaf looks there on its own.
  • If it cannot find them, or you keep photos somewhere else too, use Add location. Milleaf remembers the folders you add.
  • Tick the months you want in the list. Latest, Latest 3 and All select several at once.

Make one for me

  2. Tick the months to use.

4Edit a book

Opening a book takes you to the editor: photos on the left, the page in the middle, settings for whatever you selected on the right, and the page list at the bottom.

  • Saving: Milleaf saves as you go. Ctrl + Z undoes the last step.
  • Swap photos: drag a photo from the left into a frame. Drag one frame onto another to swap them.
  • Position and size: drag a photo inside its frame to move it, and use Alt + wheel to zoom. Drag a corner of the frame, or use Ctrl + wheel, to resize the frame.
  • Layout: select a page and pick one under Change layout on the right. The photos stay and only their arrangement changes.
  • Text, decorations and photo frames: use Add at the top. Double-click text to type in it. Speech bubbles are here too.
  • The whole book: Template at the top lays out the whole book again, and Colors changes the paper, text and accent colors. Book info has the title, binding, text size and colophon.
  • Pages: add, duplicate and delete pages in the list at the bottom. Drag to reorder them.
  • Redo the layout: Auto at the top lays out the whole book again with the same photos, or changes all the captions or the cover at once.

The ? button at the bottom right (or the ? key) lists what you can do on the current screen and the keys for it.

Photo editing

Double-click a photo in a frame to open Edit photo. Mosaic, cropping and color adjustments are all here.

  • To hide people or name tags in the shot, mark the area with Rectangle, Ellipse, Lasso or Brush on the left, then choose Mosaic, Blur or Fill on the right.
  • You can also crop, rotate and flip here.
  • For color, pick a preset such as Print or Brighter, or move the sliders for brightness, contrast and so on. You can apply the same change to every photo from the same day or the same world.
  • Your original files are never changed. You can edit again at any time after you click Apply. Save as image saves the edited photo as a PNG or JPEG.

7Updating and restoring

Update to a new version

  1. Download the new ZIP from BOOTH and unzip it to a different folder from the current one.
  2. Start the new Milleaf.exe. Your books and settings carry over, and Milleaf backs up your data when it starts.
  3. Once everything works, delete the old folder.
  • If you had a Milleaf-data folder in the old folder, choose to copy it when Milleaf asks at startup.
  • If something goes wrong, the old Milleaf.exe still works as before. Books saved in the new version open read-only in the old one, though.
  • Turn on Tell me when a new version is out in Settings to get a notice at the top right of the shelf. Milleaf reads the public version info once a day and sends nothing from your PC.

Restore from a backup

  • The first time a new version starts, Milleaf copies your books, templates and settings (not the photos).
  • In Settings, click Restore from backup, pick a point from the list and restore it. Milleaf also saves the state just before restoring, so you can go back again.

8Troubleshooting

Milleaf does not start, or closes right away

Make sure you extracted the whole ZIP and are starting Milleaf.exe from the extracted folder. If you put it in C:\Program Files, move it somewhere else. If your antivirus is blocking it, add the extracted folder to its exclusions.

"Windows protected your PC" appears

Click More info, then Run anyway (section 2).

Milleaf cannot find my VRChat photos

If you changed where VRChat saves photos, Milleaf cannot find them on its own. Use Add location and choose the folder.

"N photos in this book could not be found"

The photos were moved or deleted after you made the book, or the external drive they are on is disconnected. Put the photos back where they were and they will show again. You cannot export until the photos are found.

Loading photos takes a long time

The first time Milleaf reads a folder, it opens each photo, which can take a few minutes. It is faster from the second time.

"Fonts not on this PC"

The book uses a font this PC does not have, and a different font will be used in the export. Choose another font, or add the font in Settings under Added fonts.

Export failed

The reason follows "Export failed". It is one of these: not enough disk space, a folder Milleaf cannot write to, a file open in another app, or a folder path that is too long. Try a different folder.

The trial stopped exporting

The trial can export 3 times a day. The count resets when the date changes. The full version has no limit.

In VRChat, the book is always out and there is no menu

Modular Avatar is missing from the avatar project. Add it and upload the avatar again.

I cannot find the book's menu in VRChat

Look under More in the Expression menu. If it is not there, check in Unity that the prefab is inside your avatar.

Other players cannot turn the pages

Allow that player under Avatar Interactions in VRChat's settings.

Reporting a problem

The speech bubble button at the bottom right of the app (F8) saves a note together with a screenshot of the screen. Use Export all to a folder (text + images), then contact us through the store where you got Milleaf and include that folder.

2설치와 실행

설치 과정은 없습니다. ZIP의 압축을 풀어서 사용합니다.

  1. BOOTH에서 ZIP(Milleaf-(버전)-win-portable.zip)을 다운로드합니다.
  2. ZIP을 마우스 오른쪽 버튼으로 클릭해 ‘속성’을 열고, 아래쪽에 ‘차단 해제’ 체크 상자가 있으면 체크한 뒤 ‘확인’을 누릅니다(실행할 때 나오는 경고가 줄어듭니다).
  3. ZIP을 마우스 오른쪽 버튼으로 클릭하고 ‘압축 풀기’로 원하는 위치에 압축을 풉니다. C:\Program Files 안에는 저장하지 못할 수 있으므로 피하세요.
  4. 압축을 푼 폴더의 Milleaf.exe를 더블클릭합니다.
  5. ‘Windows의 PC 보호’가 나오면 ‘추가 정보’를 누른 다음 ‘실행’을 누릅니다. Milleaf에는 전자 서명이 없기 때문에 처음 실행할 때 나옵니다.

ZIP 안에서 바로 실행할 수는 없습니다. 백신 프로그램이 막았을 때는 압축을 푼 폴더를 예외 목록에 추가하세요.

데이터 저장 위치

  • 만든 책과 설정, 템플릿은 %APPDATA%\Milleaf에 저장됩니다. ‘설정’의 ‘데이터 위치’에 있는 ‘폴더 열기’로 열 수 있습니다.
  • 이 폴더는 앱 폴더를 지워도 남습니다. 새 버전으로 바꿔도 이전 책이 그대로 보입니다.
  • USB 메모리 등으로 가지고 다닐 때는 Milleaf.exe와 같은 위치에 Milleaf-data라는 빈 폴더를 만든 뒤 실행합니다. 데이터는 그곳에 저장됩니다.
  • 원본 스크린샷은 읽기만 하며, 변경하거나 옮기지 않습니다.
  • 그만 쓸 때는 Milleaf 폴더와 %APPDATA%\Milleaf를 삭제합니다.

3책 만들기

만드는 방법은 두 가지입니다.

  • 자동으로 만들기: 폴더만 고르면 모든 템플릿으로 조판한 후보가 나열됩니다. 가장 빠른 방법입니다.
  • 새 책: 사용할 사진을 고르고, 템플릿과 페이지 설정을 정한 뒤 조판합니다.

스크린샷 위치

  • VRChat 사진은 보통 사진\VRChat에 월별 폴더(2026-09 등)로 저장되어 있습니다. Milleaf는 이 위치를 자동으로 찾습니다.
  • 찾지 못할 때나 다른 위치에도 사진이 있을 때는 ‘위치 추가’로 고릅니다. 고른 위치는 다음부터 기억합니다.
  • 목록에서 사용할 달에 체크합니다. ‘최근’, ‘최근 3개’, ‘모두’로 한꺼번에 고를 수 있습니다.

자동으로 만들기

  1. 책장의 ‘자동으로 만들기’를 누릅니다.
  2. 사용할 달에 체크합니다.
  3. ‘책의 두께’(적게 30장·보통 60장·많게 110장·전부 사용)와 ‘글자’(넣지 않음·날짜만·날짜와 월드 이름)를 고르고 ‘만들기’를 누릅니다.
  4. 같은 사진을 모든 템플릿으로 조판한 후보가 나열됩니다. 마음에 드는 카드를 누르면 책이 됩니다.

새 책

  1. 책장의 ‘새 책’을 누릅니다.
  2. 사진 폴더: 사용할 달에 체크하고 ‘사진 불러오기’를 누릅니다. VRChat 이외의 이미지는 오른쪽의 ‘폴더 추가’로 불러올 수 있습니다.
  3. 사진 선택: 처음에는 모든 사진이 선택되어 있습니다. 사용하지 않을 사진의 표시를 해제합니다.
  4. 책 설정: 템플릿을 고르고, 제목과 사진 밀도 등을 정한 뒤 ‘책 만들기’를 누릅니다. 오른쪽 위에 현재 설정으로 조판했을 때의 페이지 수가 나옵니다.

4책 고치기

책을 열면 에디터가 됩니다. 왼쪽에 사진, 가운데에 페이지, 오른쪽에 선택한 것의 설정, 아래에 페이지 목록이 나열됩니다.

  • 저장: 자동으로 저장됩니다. Ctrl + Z로 한 단계 전으로 되돌릴 수 있습니다.
  • 사진 바꾸기: 왼쪽 사진을 페이지의 프레임으로 드래그합니다. 프레임끼리 드래그하면 서로 바뀝니다.
  • 사진의 위치와 크기: 프레임 안의 사진을 드래그하면 위치가, Alt + 휠로 확대 배율이 바뀝니다. 프레임 크기는 모서리를 드래그하거나 Ctrl + 휠로 바꿉니다.
  • 레이아웃: 페이지를 고르고 오른쪽의 ‘레이아웃 변경’에서 고릅니다. 사진은 그대로 두고 배치만 바뀝니다.
  • 글자와 장식, 사진 프레임: 위쪽의 ‘추가’에서 넣습니다. 글자는 더블클릭하면 바로 입력할 수 있습니다. 말풍선도 여기에 있습니다.
  • 책 전체의 모양: 위쪽의 ‘템플릿’으로 책 전체를 다시 조판하고, ‘배색’으로 종이와 글자 색, 포인트 색을 바꿉니다. ‘책 정보’에서는 제목과 제본 방향, 글자 크기, 판권면을 바꿀 수 있습니다.
  • 페이지: 아래 목록에서 추가, 복제, 삭제를 합니다. 드래그해서 순서를 바꿀 수 있습니다.
  • 한꺼번에 다시 조판: 위쪽의 ‘자동’으로 사진은 그대로 둔 채 책 전체를 다시 조판하거나, 캡션이나 표지를 한꺼번에 바꿀 수 있습니다.

조작 목록은 오른쪽 아래의 ‘?’나 ? 키로 나옵니다. 그 화면에서 할 수 있는 일과 키가 나열됩니다.

프레임의 사진을 더블클릭하면 ‘사진 편집’이 열립니다. 모자이크, 자르기, 색 보정은 여기서 합니다.

  • 찍힌 사람이나 이름표를 가릴 때는 왼쪽의 ‘사각형’, ‘타원’, ‘올가미’, ‘브러시’로 범위를 지정하고, 오른쪽에서 ‘모자이크’, ‘흐리기’, ‘채우기’를 고릅니다.
  • 자르기와 회전, 반전도 여기서 할 수 있습니다.
  • 색은 ‘인쇄용’, ‘밝게’ 등의 프리셋에서 고르거나 밝기와 대비를 조절합니다. 같은 날이나 같은 월드의 사진에 한꺼번에 적용할 수도 있습니다.
  • 원본 파일은 변경하지 않습니다. ‘적용’한 뒤에도 언제든지 다시 편집할 수 있습니다. ‘이미지로 저장’으로 편집한 1장을 PNG나 JPEG로 저장할 수 있습니다.

7새 버전으로 바꾸기·되돌리기

새 버전으로 바꾸기

  1. BOOTH에서 새 ZIP을 다운로드해, 지금 폴더와는 다른 위치에 압축을 풉니다.
  2. 새 Milleaf.exe를 실행합니다. 책과 설정은 그대로 사용할 수 있습니다. 실행할 때 그때까지의 데이터 백업도 만듭니다.
  3. 문제없이 동작하면 이전 폴더를 삭제합니다.
  • 이전 폴더에 Milleaf-data를 만들어 두었을 때는 실행할 때 나오는 안내에서 ‘복사해서 사용’을 고릅니다.
  • 잘 동작하지 않을 때는 이전 폴더의 Milleaf.exe로 지금까지처럼 사용할 수 있습니다. 다만 새 버전에서 저장한 책은 이전 버전에서는 보기만 할 수 있습니다.
  • ‘설정’의 ‘새 버전이 나오면 알림’을 켜면 새 버전이 나왔을 때 책장 오른쪽 위에 알림이 나옵니다. 하루 한 번 공개된 버전 정보를 읽기만 하며, 이쪽에서는 아무것도 보내지 않습니다.

백업에서 복원

  • 새 버전을 처음 실행할 때 그때까지의 책과 템플릿, 설정을 자동으로 복사해 둡니다(사진 자체는 복사하지 않습니다).
  • ‘설정’의 ‘백업에서 복원’에서 목록의 시점을 고르고 ‘되돌리기’를 누릅니다. 복원하기 직전의 상태도 복사해 두므로 나중에 다시 되돌릴 수 있습니다.

8문제가 생겼을 때

실행되지 않거나 바로 닫힘

ZIP의 압축을 모두 푼 뒤, 압축을 푼 폴더의 Milleaf.exe를 실행하고 있는지 확인하세요. C:\Program Files 안에 둔 경우에는 다른 위치로 옮깁니다. 백신 프로그램이 막고 있는 경우에는 압축을 푼 폴더를 예외 목록에 추가합니다.

‘Windows의 PC 보호’가 나옴

‘추가 정보’를 누른 다음 ‘실행’을 누릅니다(2장).

VRChat 사진을 찾을 수 없음

VRChat 설정에서 사진 저장 위치를 바꾼 경우에는 자동으로 찾지 못합니다. ‘위치 추가’로 사진 폴더를 고르세요.

‘이 책의 사진 N장을 찾을 수 없습니다’가 나옴

책을 만든 뒤에 사진을 옮겼거나 삭제했거나, 사진이 있는 외장 드라이브가 분리되어 있습니다. 사진을 원래 위치로 되돌리면 다시 표시됩니다. 사진을 찾을 수 없는 동안에는 내보낼 수 없습니다.

사진을 불러오는 데 시간이 걸림

처음 읽는 폴더는 사진을 한 장씩 열기 때문에 몇 분 걸릴 수 있습니다. 두 번째부터는 빨라집니다.

‘이 PC에 없는 글꼴’이 나옴

책에서 사용하는 글꼴이 이 PC에 없습니다. 그대로 내보내면 다른 글꼴로 나옵니다. 글꼴을 다시 고르거나, ‘설정’의 ‘추가한 글꼴’에서 글꼴을 추가하세요.

내보낼 수 없음

‘내보내기 실패’ 뒤에 이유가 나옵니다. 디스크 여유 공간이 부족하거나, 쓸 수 없는 폴더를 골랐거나, 파일을 다른 앱에서 열고 있거나, 폴더 경로가 너무 긴 경우 중 하나입니다. 다른 폴더를 골라 다시 시도하세요.

체험판에서 내보낼 수 없게 됨

체험판의 내보내기는 하루 3회까지입니다. 날짜가 바뀌면 다시 3회가 됩니다. 정식판에는 횟수 제한이 없습니다.

VRChat에서 책이 나온 채로 있고 메뉴도 없음

아바타 프로젝트에 Modular Avatar가 들어 있지 않습니다. 넣은 뒤 다시 업로드하세요.

VRChat에서 메뉴를 찾을 수 없음

Expression 메뉴의 ‘More’ 안을 확인하세요. 찾을 수 없을 때는 Unity에서 프리팹이 아바타 안에 있는지 확인합니다.

다른 사람이 페이지를 넘길 수 없음

VRChat 설정의 ‘Avatar Interactions’에서 그 사람을 허용하세요.

문제를 알리고 싶을 때

앱 오른쪽 아래의 말풍선 버튼(F8)으로 그 화면의 스크린샷과 함께 메모를 남길 수 있습니다. ‘폴더로 모두 내보내기 (텍스트 + 이미지)’로 만든 폴더를 첨부해 Milleaf를 받은 스토어를 통해 문의해 주세요.

1簡介

Milleaf 是用 VRChat 截圖製作寫真集的 Windows 應用程式。選擇資料夾後，會把相似的照片歸成一組，並依照範本排出頁面。排好之後，可以逐頁修改照片、文字與裝飾。

選擇照片
從每月的資料夾讀取，把連拍和相似的照片歸成 1 張
自動排版
範本共 5 種（簡約、雜誌風、底片・拍立得、滿滿的、漫畫）。加入另售的官方追加範本後還會增加
修改
替換照片、更改版面、加入文字與裝飾、馬賽克、裁切、調整顏色
匯出
PDF、連號圖片（PNG、JPEG）、電子書（EPUB）、印刷廠交稿資料、可在 VRChat 中閱讀的書（unitypackage）

系統需求

顯示語言

2安裝與啟動

不需要安裝。解壓縮 ZIP 後即可使用。

  1. 從 BOOTH 下載 ZIP（Milleaf-（版本）-win-portable.zip）。
  2. 在 ZIP 上按右鍵開啟「內容」，如果下方有「解除封鎖」核取方塊，請勾選後按「確定」（可以減少啟動時的警告）。
  3. 在 ZIP 上按右鍵，用「解壓縮全部」解壓縮到想要的位置。C:\Program Files 內有時無法寫入，請避開。
  4. 按兩下解壓縮後資料夾中的 Milleaf.exe。
  5. 如果出現「Windows 已保護您的電腦」，請按「其他資訊」，再按「仍要執行」。Milleaf 沒有數位簽章，所以第一次啟動時會出現。

無法直接從 ZIP 內啟動。如果防毒軟體阻擋了啟動，請把解壓縮後的資料夾加入排除清單。

資料的存放位置

  • 製作的書、設定與範本會儲存在 %APPDATA%\Milleaf。可以用「設定」中「資料位置」的「開啟資料夾」開啟。
  • 刪除應用程式的資料夾後，這個資料夾仍會保留。更新到新版本後，之前的書也會照樣出現。
  • 要用 USB 隨身碟等攜帶時，請先在 Milleaf.exe 所在的位置建立名為 Milleaf-data 的空資料夾，再啟動。資料會儲存在那裡。
  • 原始截圖只會讀取，不會修改也不會移動。
  • 不再使用時，請刪除 Milleaf 的資料夾與 %APPDATA%\Milleaf。

3製作書

製作方法有 2 種。

  • 自動做一本：只要選擇資料夾，就會列出用所有範本排好的候選。這是最快的方法。
  • 新書：先選要用的照片，決定範本與頁面設定後再排版。

截圖位置

  • VRChat 的照片通常以每月一個資料夾（例如 2026-09）儲存在 圖片\VRChat。Milleaf 會自動尋找這個位置。
  • 找不到，或其他位置也有照片時，請用「新增位置」選擇。選過的位置下次會記住。
  • 在清單中勾選要使用的月份。可以用「最近」「最近 3 個」「全部」一次選取。

自動做一本

  1. 按下書架上的「自動做一本」。
  2. 勾選要使用的月份。
  3. 選擇「書的厚度」（少一些 30 張、一般 60 張、多一些 110 張、全部使用）與「文字」（不加入、只有日期、日期與世界名稱），再按「製作」。
  4. 會列出用所有範本排好同一批照片的候選。按下喜歡的卡片，就會做成書。

新書

  1. 按下書架上的「新書」。
  2. 照片資料夾：勾選要使用的月份，再按「載入照片」。VRChat 以外的圖片，可以從右邊的「新增資料夾」載入。
  3. 選擇照片：一開始全部都已選取。取消不使用的照片的標記。

4修改書

開啟書後會進入編輯器。左邊是照片，中間是頁面，右邊是所選項目的設定，下方是頁面清單。

  • 儲存：會自動儲存。按 Ctrl + Z 可以回到上一步。
  • 替換照片：把左邊的照片拖曳到頁面的框中。在框與框之間拖曳，會互相交換。
  • 照片的位置與大小：拖曳框中的照片可以改變位置，用 Alt + 滾輪可以改變縮放。框的大小可以拖曳角落，或用 Ctrl + 滾輪改變。
  • 版面：選擇頁面，從右邊的「更改版面」中選擇。照片保持不變，只改變配置。
  • 文字、裝飾與照片框：從上方的「新增」加入。文字按兩下即可直接輸入。對話框也在這裡。
  • 整本書的外觀：用上方的「範本」重新排整本書，用「配色」更改紙張與文字的顏色及強調色。在「書籍資訊」中可以更改標題、裝訂方向、文字大小與版權頁。
  • 頁面：在下方的清單中新增、複製或刪除。可以拖曳重新排序。
  • 一次重新排版：用上方的「自動」，可以保留照片重新排整本書，或一次更改圖說和封面。

操作一覽可以用右下角的「?」或 ? 鍵叫出。會列出該畫面能做的操作與按鍵。

編輯照片

按兩下框中的照片，會開啟「編輯照片」。馬賽克、裁切、調整顏色都在這裡進行。

  • 也可以在這裡裁切、旋轉與翻轉。
  • 顏色可以從「印刷用」「調亮」等預設中選擇，或調整亮度與對比。也可以一次套用到同一天或同一個世界的照片。
  • 不會修改原始檔案。「套用」後也隨時可以重新編輯。用「存為圖片」可以把編輯後的 1 張存成 PNG 或 JPEG。

7更新與還原

更新到新版本

  1. 從 BOOTH 下載新的 ZIP，解壓縮到與目前資料夾不同的位置。
  2. 啟動新的 Milleaf.exe。書與設定可以照常使用。啟動時也會備份之前的資料。
  3. 確認運作沒有問題後，刪除舊的資料夾。
  • 如果在舊資料夾中建立了 Milleaf-data，請在啟動時出現的提示中選擇「複製後使用」。
  • 無法正常運作時，可以用舊資料夾的 Milleaf.exe 照常使用。不過，用新版本儲存的書在舊版本中只能檢視。
  • 開啟「設定」中的「有新版本時通知」後，有新版本時會在書架右上角顯示通知。每天只讀取一次公開的版本資訊，不會從這裡傳送任何資料。

從備份還原

  • 第一次啟動新版本時，會自動複製之前的書、範本與設定（不會複製照片本身）。
  • 在「設定」的「從備份還原」中，從清單選擇時間點，再按「復原」。還原前的狀態也會複製保存，之後可以再還原回來。

8遇到問題時

無法啟動，或馬上關閉

請確認已將 ZIP 全部解壓縮，並且啟動的是解壓縮後資料夾中的 Milleaf.exe。如果放在 C:\Program Files 內，請移到其他位置。如果是防毒軟體阻擋，請把解壓縮後的資料夾加入排除清單。

出現「Windows 已保護您的電腦」

按「其他資訊」，再按「仍要執行」（第 2 章）。

找不到 VRChat 的照片

如果在 VRChat 的設定中變更了照片的儲存位置，就無法自動找到。請用「新增位置」選擇照片的資料夾。

出現「找不到這本書中的 N 張照片」

製作書之後移動或刪除了照片，或存放照片的外接磁碟機已拔除。把照片放回原來的位置，就會再次顯示。找不到照片期間無法匯出。

載入照片很花時間

第一次讀取的資料夾會逐張開啟照片，可能需要幾分鐘。第二次起會變快。

出現「這台電腦沒有的字型」

書中使用的字型不在這台電腦上。直接匯出會以其他字型輸出。請重新選擇字型，或從「設定」的「新增的字型」加入字型。

無法匯出

「匯出失敗」後面會顯示原因。原因是以下其中之一：磁碟空間不足、選擇了無法寫入的資料夾、檔案正在其他應用程式中開啟、資料夾路徑太長。請選擇其他資料夾再試一次。

體驗版無法再匯出

體驗版每天最多匯出 3 次。日期變更後會恢復為 3 次。正式版沒有次數限制。

在 VRChat 中書一直顯示著，也沒有選單

虛擬角色的專案中沒有加入 Modular Avatar。加入後請重新上傳。

在 VRChat 中找不到選單

請查看 Expression 選單的「More」裡面。找不到時，請在 Unity 中確認 Prefab 是否在虛擬角色裡。

其他人無法翻頁

請在 VRChat 設定的「Avatar Interactions」中允許那個人。

想回報問題

用應用程式右下角的對話氣泡按鈕（F8），可以連同該畫面的截圖留下筆記。請附上用「全部匯出到資料夾（文字 + 圖片）」產生的資料夾，透過取得 Milleaf 的商店聯絡我們。

2安装与启动

无需安装。解压 ZIP 后即可使用。

  1. 从 BOOTH 下载 ZIP（Milleaf-（版本）-win-portable.zip）。
  2. 右键单击 ZIP 打开「属性」，如果下方有「解除锁定」复选框，请勾选后点击「确定」（可以减少启动时的警告）。
  3. 右键单击 ZIP，用「全部解压缩」解压到想要的位置。C:\Program Files 中有时无法写入，请避开。
  4. 双击解压后文件夹中的 Milleaf.exe。
  5. 如果出现「Windows 已保护你的电脑」，请点击「更多信息」，再点击「仍要运行」。Milleaf 没有数字签名，所以第一次启动时会出现。

无法直接从 ZIP 内启动。如果杀毒软件阻止了启动，请把解压后的文件夹加入排除项。

数据的存放位置

  • 制作的书、设置和模板会保存在 %APPDATA%\Milleaf。可以用「设置」中「数据位置」的「打开文件夹」打开。
  • 删除应用的文件夹后，这个文件夹仍会保留。更新到新版本后，之前的书也会照样显示。
  • 要用 U 盘等随身携带时，请先在 Milleaf.exe 所在的位置创建名为 Milleaf-data 的空文件夹，再启动。数据会保存在那里。
  • 原始截图只会读取，不会修改也不会移动。
  • 不再使用时，请删除 Milleaf 的文件夹和 %APPDATA%\Milleaf。

3制作书

制作方法有 2 种。

  • 自动做一本：只要选择文件夹，就会列出用所有模板排好的候选。这是最快的方法。
  • 新书：先选要用的照片，决定模板和页面设置后再排版。

截图位置

  • VRChat 的照片通常以每月一个文件夹（例如 2026-09）保存在 图片\VRChat。Milleaf 会自动查找这个位置。
  • 找不到，或其他位置也有照片时，请用「添加位置」选择。选过的位置下次会记住。
  • 在列表中勾选要使用的月份。可以用「最近」「最近 3 个」「全部」一次选择。

自动做一本

  1. 点击书架上的「自动做一本」。
  2. 勾选要使用的月份。
  3. 选择「书的厚度」（少一些 30 张、一般 60 张、多一些 110 张、全部使用）和「文字」（不加入、只有日期、日期与世界名称），再点击「制作」。
  4. 会列出用所有模板排好同一批照片的候选。点击喜欢的卡片，就会做成书。

新书

  1. 点击书架上的「新书」。
  2. 照片文件夹：勾选要使用的月份，再点击「加载照片」。VRChat 以外的图片，可以从右侧的「添加文件夹」加载。
  3. 选择照片：一开始全部都已选中。取消不使用的照片的标记。
  4. 书籍设置：选择模板，决定标题、照片密度等，再点击「制作」。右上角会显示按当前设置排版时的页数。

4修改书

打开书后会进入编辑器。左侧是照片，中间是页面，右侧是所选项目的设置，下方是页面列表。

  • 保存：会自动保存。按 Ctrl + Z 可以回到上一步。
  • 替换照片：把左侧的照片拖到页面的框中。在框与框之间拖动，会互相交换。
  • 照片的位置和大小：拖动框中的照片可以改变位置，用 Alt + 滚轮可以改变缩放。框的大小可以拖动角落，或用 Ctrl + 滚轮改变。
  • 版面：选择页面，从右侧的「更改版面」中选择。照片保持不变，只改变配置。
  • 文字、装饰和照片框：从上方的「添加」加入。文字双击即可直接输入。对话框也在这里。
  • 整本书的外观：用上方的「模板」重新排整本书，用「配色」更改纸张和文字的颜色及强调色。在「书籍信息」中可以更改标题、装订方向、文字大小和版权页。
  • 页面：在下方的列表中添加、复制或删除。可以拖动重新排序。
  • 一次重新排版：用上方的「自动」，可以保留照片重新排整本书，或一次更改图注和封面。

操作一览可以用右下角的「?」或 ? 键调出。会列出该画面能做的操作和按键。

编辑照片

双击框中的照片，会打开「编辑照片」。马赛克、裁剪、调整颜色都在这里进行。

  • 要遮住入镜的人或名牌时，用左侧的「矩形」「椭圆」「套索」「画笔」指定范围，再在右侧选择「马赛克」「模糊」「填色」。
  • 也可以在这里裁剪、旋转和翻转。
  • 颜色可以从「印刷用」「调亮」等预设中选择，或调整亮度和对比度。也可以一次应用到同一天或同一个世界的照片。
  • 不会修改原始文件。「应用」后也随时可以重新编辑。用「保存为图片」可以把编辑后的 1 张保存为 PNG 或 JPEG。

6可在 VRChat 中阅读的书

可以导出让虚拟形象拿着、在 VRChat 中翻页的书。适用于 PC 版 VRChat，不支持 Quest。

需要的东西

  • 可以上传虚拟形象的 Unity 项目（Unity 2022.3 和 VRChat SDK 的 Avatars。已在 2022.3.22f1 确认可以运行）
  • Modular Avatar（已在 1.18 确认可以运行）。请先用 VCC（VRChat Creator Companion）或 ALCOM 添加到项目中

导出设置

  • 选择书的高度（拿在手上时为 15～25 cm）、贴图大小（1024、2048、4096）和附加位置（左手、右手、胸前）。在桌面模式（不用 VR）下使用时，「胸前」是容易看的位置。
  • 「虚拟形象增加的容量」会显示贴图内存和下载大小。
  • 书中的照片其他人也能看到。

添加到虚拟形象

  1. 在 Unity 中打开虚拟形象的项目，导入导出的 .unitypackage（双击，或用 Assets → Import Package → Custom Package）。
  2. 把 Assets/Milleaf/（标题）_（月日）/Milleaf.prefab 拖到 Hierarchy 中的虚拟形象里。会自动重新放到所选的位置（手或胸前）。
  3. 直接上传。
  • 要改变方向时，在 Hierarchy 中选择 Milleaf，更改 Inspector 的 Rotation。
  • 手的位置偏移时，请使用 Unity 菜单的 Tools → Milleaf → 本を手に合わせ直す（重新把书对齐到手上）。
  • 重新导出同一本书并导入后，之前的内容会更新。同一本书每个虚拟形象只能放 1 本。
  • 书的文件夹中附有 README.txt。

7更新与恢复

更新到新版本

  1. 从 BOOTH 下载新的 ZIP，解压到与当前文件夹不同的位置。
  2. 启动新的 Milleaf.exe。书和设置可以照常使用。启动时也会备份之前的数据。
  3. 确认运行没有问题后，删除旧的文件夹。
  • 如果在旧文件夹中创建了 Milleaf-data，请在启动时出现的提示中选择「复制后使用」。
  • 无法正常运行时，可以用旧文件夹的 Milleaf.exe 照常使用。不过，用新版本保存的书在旧版本中只能查看。
  • 打开「设置」中的「有新版本时通知」后，有新版本时会在书架右上角显示通知。每天只读取一次公开的版本信息，不会从这里发送任何数据。

从备份恢复

  • 第一次启动新版本时，会自动复制之前的书、模板和设置（不会复制照片本身）。
  • 在「设置」的「从备份恢复」中，从列表选择时间点，再点击「撤销」。恢复前的状态也会复制保存，之后可以再恢复回来。

8遇到问题时

无法启动，或马上关闭

请确认已将 ZIP 全部解压，并且启动的是解压后文件夹中的 Milleaf.exe。如果放在 C:\Program Files 中，请移到其他位置。如果是杀毒软件阻止，请把解压后的文件夹加入排除项。

出现「Windows 已保护你的电脑」

点击「更多信息」，再点击「仍要运行」（第 2 章）。

找不到 VRChat 的照片

如果在 VRChat 的设置中更改了照片的保存位置，就无法自动找到。请用「添加位置」选择照片的文件夹。

出现「找不到这本书中的 N 张照片」

制作书之后移动或删除了照片，或存放照片的外接驱动器已拔出。把照片放回原来的位置，就会再次显示。找不到照片期间无法导出。

加载照片很花时间

第一次读取的文件夹会逐张打开照片，可能需要几分钟。第二次起会变快。

出现「这台电脑没有的字体」

书中使用的字体不在这台电脑上。直接导出会以其他字体输出。请重新选择字体，或从「设置」的「添加的字体」添加字体。

无法导出

「导出失败」后面会显示原因。原因是以下其中之一：磁盘空间不足、选择了无法写入的文件夹、文件正在其他应用中打开、文件夹路径太长。请选择其他文件夹再试一次。

体验版无法再导出

体验版每天最多导出 3 次。日期变更后会恢复为 3 次。正式版没有次数限制。

在 VRChat 中书一直显示着，也没有菜单

虚拟形象的项目中没有添加 Modular Avatar。添加后请重新上传。

在 VRChat 中找不到菜单

请查看 Expression 菜单的「More」里面。找不到时，请在 Unity 中确认 Prefab 是否在虚拟形象里。

其他人无法翻页

请在 VRChat 设置的「Avatar Interactions」中允许那个人。

想反馈问题

用应用右下角的对话气泡按钮（F8），可以连同该画面的截图留下笔记。请附上用「全部导出到文件夹（文字 + 图片）」生成的文件夹，通过获得 Milleaf 的商店联系我们。
